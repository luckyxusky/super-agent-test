# ✦ Starlight Memo

A beautiful, interactive memo page with an animated starfield background.

## Features

- **Twinkling starfield** - 150 animated stars with varying sizes and twinkle speeds
- **Shooting stars** - Periodic shooting star animations across the sky
- **Floating nebulae** - Soft colored glow effects that drift gently
- **Glassmorphism cards** - Frosted glass memo cards with gradient accents
- **Persistent storage** - Memos saved to localStorage (survives page refresh)
- **Keyboard shortcut** - Ctrl+Enter to quickly save
- **Responsive design** - Works on desktop and mobile

## Usage

Simply open `memo.html` in any modern browser. Start typing your thoughts and click "Save" or press Ctrl+Enter. Your memos will be persisted locally.
